# Task 2 – Grade Calculator
## Internship
CodSoft – Java Development Internship
## Task Description
This project is a console-based Java application that calculates the total marks, average percentage, and grade of a student based on marks obtained in multiple subjects.
## Features
- Accepts marks (out of 100) for multiple subjects
- Calculates total marks
- Calculates average percentage
- Assigns grade based on percentage
- Includes input validation
## Technologies Used
- Java
- JDK
- Console-based Interface
## Java Concepts Used
- Scanner class
- Loops
- Conditional statements
- Variables and data types
- Input validation
